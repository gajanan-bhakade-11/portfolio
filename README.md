# Portfolio – Gajanan Bhakade
Static site: no build step.
- Open `index.html` in a browser, or run `python -m http.server` in this folder.
- Deploy free: drag this folder to Netlify Drop, or push to a GitHub repo and enable GitHub Pages.
- Edit text in `index.html`, colors in `:root` of `styles.css`, the hero chat demo in `script.js`.
- Replace each project's GitHub link with the exact repository URL. Replace `assets/resume.pdf` when your resume changes.
